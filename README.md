# Sunlit Path

An English learning web app for high-school students (Logic and Expression I), designed for students with physical and intellectual disabilities. Runs in the browser; no login and no data is sent to a server in this public version.

- Version: v0.18 public
- Levels: Junior high review (CEFR A1–A2) and up to B1. B2–C2 are in preparation.
- Dictionary: CEFR A1–A2 (2,557 words) and B1 (2,325 words)
- "My theme": students build their own word book and route. Saved only on the device.

Note: The levels (A1–C2) are practice stages based on word lists such as CEFR-J. This app is not test preparation for Eiken or CEFR exams and does not certify a level.
